title: "Ige: jövő idő"
weight: 120
---

Nincs önálló jövő idejű igealak — a jövőt a **fog** segédige és a főige főnévi igeneve (**-ni**) együtt fejezi ki. A **fog** ragozódik alanyi és tárgyas ragozásban egyaránt, a főnévi igenév változatlan marad.

## Alanyi ragozás

| | fog | + főnévi igenév |
|---|---|---|
| (én) | fog**ok** | fogok **várni** |
| (te) | fog**sz** | fogsz **várni** |
| (ő) | fog | fog **várni** |
| (mi) | fog**unk** | fogunk **várni** |
| (ti) | fog**tok** | fogtok **várni** |
| (ők) | fog**nak** | fognak **várni** |

## Tárgyas ragozás

| | fog | + főnévi igenév |
|---|---|---|
| (én) | fog**om** | fogom **várni** |
| (te) | fog**od** | fogod **várni** |
| (ő) | fog**ja** | fogja **várni** |
| (mi) | fog**juk** | fogjuk **várni** |
| (ti) | fog**játok** | fogjátok **várni** |
| (ők) | fog**ják** | fogják **várni** |

- *Fogok **egy könyvet** olvasni.* (alanyi, határozatlan tárgy)
- *Fogom **a könyvet** olvasni.* / gyakoribb: *El fogom olvasni **a könyvet**.* (tárgyas)

## Igekötős igénél: az igekötő elválik

Ha az ige igekötős (lásd a „Mondattan” fejezetet), az igekötő rendszerint a **fog** elé kerül, nem az igenévhez tapadva:

- *megnézem* (jelen) → ***Meg** fogom nézni.* (nem *fogom megnézni*, bár ez is előfordul köznyelvben)
- *elolvasom* → ***El** fogom olvasni.*

## Jelen idő jövő értelemben

Rögzített tervnél, menetrendnél a jelen idő gyakoribb, mint a **fog**-os alak:

- *Holnap **utazom**.* (természetesebb, mint *holnap fogok utazni*)
- *A vonat **indul** kilenckor.*

A **fog**-os alak inkább bizonytalanabb, távolabbi vagy ígéretszerű jövőt jelez: *Egyszer **fogok** még Budapesten **élni**.*
