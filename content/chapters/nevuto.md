A névutó külön szó, a főnév **után** áll, és a főnév előtte alanyesetben marad — nem úgy, mint az esetrag, amely a szóhoz tapad. Sok névutónak, akárcsak a helyviszonyragoknak, három iránya van: hol, hova, honnan.

## A hely névutói: három irány

| | hol? | hova? | honnan? |
|---|---|---|---|
| alatt | **alatt** | **alá** | **alól** |
| fölött | **fölött** | **fölé** | **fölül** |
| mellett | **mellett** | **mellé** | **mellől** |
| mögött | **mögött** | **mögé** | **mögül** |
| előtt | **előtt** | **elé** | **elől** |
| között | **között** | **közé** | **közül** |

- *az asztal **alatt*** (hol?) → *az asztal **alá*** (hova?) → *az asztal **alól*** (honnan?)
- *a ház **mögött***, *a fa **mellett***, *a két épület **között***

## Egyirányú névutók

Ezeknek nincs hol/hova/honnan hármasuk — egyetlen viszonyt fejeznek ki.

| Névutó | Jelentés | Példa |
|---|---|---|
| **számára**, **részére** | -nak/-nek helyett, nyomatékosabban | *ez a levél a főnök **számára** készült* |
| **miatt** | ok | *az eső **miatt** maradtunk otthon* |
| **ellen** | szembenállás | *harcol a betegség **ellen*** |
| **helyett** | csere | *tea **helyett** kávét kérek* |
| **szerint** | vélemény, forrás | *a hír **szerint** holnap havazik* |
| **nélkül** | hiány | *cukor **nélkül** iszom a kávét* |
| **által** | cselekvő (szenvedő értelmű szerkezetben) | *a titkár **által** küldött levél* |
| **keresztül** | átmenet | *a parkon **keresztül** megyünk* |

## Névmási alak: a névutó személyragozva

Ha a névutó vonzata névmás, nem a névmás áll a névutó előtt, hanem a névutó maga vesz fel személyjelet — ugyanazzal a jelrenddel, mint a birtokos személyjel.

| | alatt | mellett |
|---|---|---|
| (én) | alatt**am** | mellett**em** |
| (te) | alatt**ad** | mellett**ed** |
| (ő) | alatt**a** | mellett**e** |
| (mi) | alatt**unk** | mellett**ünk** |
| (ti) | alatt**atok** | mellett**etek** |
| (ők) | alatt**uk** | mellett**ük** |

- *Ki ül melletted? — Péter ül **mellettem**.*
- *A kutya **alattam** alszik.*
