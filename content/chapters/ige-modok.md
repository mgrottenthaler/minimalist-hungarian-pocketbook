A kijelentő módon (jelen, múlt, jövő) kívül két módja van a magyar igének: a **feltételes** és a **felszólító** — utóbbi egyben az óhajtó/kötőmódi szerepet is átveszi, külön kötőmód nélkül.

## Feltételes mód: jel -na/-ne

| | vár, alanyi | vár, tárgyas | kér, alanyi | kér, tárgyas |
|---|---|---|---|---|
| (én) | vár**nék** | vár**nám** | kér**nék** | kér**ném** |
| (te) | vár**nál** | vár**nád** | kér**nél** | kér**néd** |
| (ő) | vár**na** | vár**ná** | kér**ne** | kér**né** |
| (mi) | vár**nánk** | vár**nánk** | kér**nénk** | kér**nénk** |
| (ti) | vár**nátok** | vár**nátok** | kér**nétek** | kér**nétek** |
| (ők) | vár**nának** | vár**nák** | kér**nének** | kér**nék** |

> Többes szám 1. és 2. személyében a két ragozás **egybeesik** (*várnánk, várnátok*) — csak az egyes szám és a T/3 különbözik.

Használat: feltétel, udvarias kérés, kívánság.

- *Ha lenne időm, **elmennék**.*
- ***Kérnék** egy kávét.* — udvarias kérés, nem parancs
- *Jó **lenne** most pihenni.*

## Felszólító mód: jel -j-

| | vár | kér | ül |
|---|---|---|---|
| (én) | vár**jak** | kér**jek** | ül**jek** |
| (te) | **várj** | **kérj** | **ülj** |
| (ő) | vár**jon** | kér**jen** | ül**jön** |
| (mi) | vár**junk** | kér**jünk** | ül**jünk** |
| (ti) | vár**jatok** | kér**jetek** | ül**jetek** |
| (ők) | vár**janak** | kér**jenek** | ül**jenek** |

> A tő végén álló **-s, -sz, -z, -dz, -t** a **-j**-vel összeolvad: *olvas → olvass, olvasson*; *néz → nézz, nézzen*; *fest → fess, fessen*. Más mássalhangzó után a **-j** egyszerűen hozzáragad: *mond → mondj, mondjon*; *tanul → tanulj, tanuljon*.

### Tárgyas ragozásban: rövid E/2 alak

A 2. sz.-ben a köznyelv a rövid, **-j** nélküli alakot használja: a tő közvetlenül **-d**-t kap.

| | kér, tárgyas |
|---|---|
| (én) | kér**jem** |
| (te) | **kérd** |
| (ő) | kér**je** |
| (mi) | kér**jük** |
| (ti) | kér**jétek** |
| (ők) | kér**jék** |

- *Várd meg!* (nem *várjad meg*, bár ez is helyes, csak választékosabb)
- *Mondd meg!* *Kérd el!*

## Használat: parancs és hogy-mellékmondat

Parancsra közvetlenül, kötőszó nélkül:

- *Gyere ide!* *Ne menj el!*

Kívánságot, célt, szükségességet kifejező főmondat után **hogy** + felszólító mód követi — ez pótolja a kötőmódot:

- *Azt akarom, **hogy gyere** ide.*
- *Szeretném, **hogy elolvasd** ezt a könyvet.*

**Kell** után főnévi igenévvel és birtokos személyjellel gyakoribb, mint *hogy* + felszólító mód: *Mennem **kell*** (nem szükségszerűen *kell, hogy menjek*, bár ez is előfordul).
