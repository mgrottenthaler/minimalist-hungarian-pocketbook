A birtokviszonyt nem külön birtokos névmás fejezi ki, hanem **birtokos személyjel** a birtokolt szón: *a könyvem*, *a házad*. A névmás csak nyomatékkor vagy egyértelműsítéskor jelenik meg mellette.

## Egy birtok, mássalhangzós tő

| | ház (mély) | kert (magas) |
|---|---|---|
| (én) | ház**am** | kert**em** |
| (te) | ház**ad** | kert**ed** |
| (ő) | ház**a** | kert**e** |
| (mi) | ház**unk** | kert**ünk** |
| (ti) | ház**atok** | kert**etek** |
| (ők) | ház**uk** | kert**ük** |

## Egy birtok, magánhangzós tő

Itt a személyjel **-j-** elemmel bővül a 3. személyben.

| | autó (mély) | kesztyű (magas) |
|---|---|---|
| (én) | autó**m** | kesztyű**m** |
| (te) | autó**d** | kesztyű**d** |
| (ő) | autó**ja** | kesztyű**je** |
| (mi) | autó**nk** | kesztyű**nk** |
| (ti) | autó**tok** | kesztyű**tök** |
| (ők) | autó**juk** | kesztyű**jük** |

> Az **apa**, **anya**, **fiú** — és néhány velük rokon rokonságnév — rendhagyó: **apja**, **anyja**, **fia** (nem *apája, anyája, fiúja*).

## Több birtok: a -i jel

Ha a birtokolt dolog többes számú, a jel nem a szokásos **-k**, hanem **-i** — a birtokos személyjel elé illesztve.

| | könyv (egy) | könyv (több) |
|---|---|---|
| (én) | könyv**em** | könyv**eim** |
| (te) | könyv**ed** | könyv**eid** |
| (ő) | könyv**e** | könyv**ei** |
| (mi) | könyv**ünk** | könyv**eink** |
| (ti) | könyv**etek** | könyv**eitek** |
| (ők) | könyv**ük** | könyv**eik** |

## A birtokos névmás: csak nyomatékkor

A birtokos személyjel önmagában elég; **én / te / ő / mi / ti / ők** hozzáadása a birtokolt elé csak kiemelést vagy szembeállítást jelez, a személyjel akkor is ott marad a főnéven:

- *a könyvem* — semleges
- *az **én** könyvem* — nem a tiéd

## Önálló birtokos névmás: enyém, tiéd...

Birtokolt főnév nélkül, önmagában álló mondatrészként — leggyakrabban állítmányként.

| | Alak |
|---|---|
| (én) | **enyém** |
| (te) | **tiéd** |
| (ő) | **övé** |
| (mi) | **miénk** |
| (ti) | **tiétek** |
| (ők) | **övék** |

- *Ez a könyv az **enyém**.* — nem *az én könyvem*, ha nincs mellette megnevezve a könyv.
- *Kié ez a toll? — Az **övé**.*

## Birtokos szerkezet két főnévvel

A birtokos maga is állhat főnévként, rag nélkül, közvetlenül a birtokolt előtt — vagy **-nak/-nek** raggal, ha a birtokolt szótól elválasztva áll, vagy nyomatékos:

- *Péter könyve* — közvetlenül egymás mellett, rag nélkül
- *Péternek a könyve* — ugyanaz, elöl kiemelve: *Péternek a könyve itt van, nem Annáé.*

## A birtoklás kifejezése: van + részes eset

A magyarban nincs önálló „birtokolni” ige — a **van** és a birtokos részes esete (**-nak/-nek**) fejezi ki a birtoklást, a birtokolt főnéven pedig ott a személyjel is:

- *Nekem van egy autóm.* — nyomatékkal; semlegesen elég: *Van egy autóm.*
- *Péternek van egy háza.*
- *Nincs időnk.* — tagadva a **van** helyett **nincs** áll.
